# Artemis II mission calendar

I had a hard time finding exact times for the notable events of the Artemis II Moon flyby
mission, so I created this repo to provide them.

You can find the notable events and times below, or add them to your favorite calendar app via
the [public ICS file](https://jkronborg.github.io/artemis-2-calendar/events.ics). If you add it
as a calendar subscription, you will automatically receive updates if any are to come.

Sources:

- [Artemis II Press Kit](https://www.nasa.gov/artemis-ii-press-kit/)
- [Artemis II Overview Timeline
  document](https://www.nasa.gov/wp-content/uploads/2026/01/artemis-ii-overview-timeline-public-final.pdf)
- [NASA Sets Coverage for Artemis II Moon
  Mission](https://www.nasa.gov/missions/artemis/artemis-2/nasa-sets-coverage-for-artemis-ii-moon-mission/)
